# SkillTrack — Placement Prep Platform 🚀

> **Learn · Practice · Analyze · Improve** — placement preparation driven by real results.

SkillTrack is an interactive, browser-based placement preparation platform designed to help students and job seekers assess, practice, and enhance their quantitative aptitude, logical reasoning, verbal ability, and core computer science technical skills.

🌐 **Live Demo:** [https://pauljebakumar.github.io/SkillTrack/](https://pauljebakumar.github.io/SkillTrack/)

---

## 🌟 Key Features

- 📊 **Dynamic Readiness Dashboard**: Real-time readiness indicator, score trends, streak tracking, and personalized daily tasks.
- 🎯 **Targeted Topic Practice**: Instant feedback and step-by-step explanations for Quantitative Aptitude, Logical Reasoning, Verbal Ability, SQL & DBMS, Java & OOP, and Operating Systems.
- ⏱️ **Timed Mock Assessments**: 10-question mixed tests with negative marking, review flags, and comprehensive performance analysis.
- 📈 **Skill Analysis**: Objective readiness benchmarks with visual rating bars, weak-topic detection, and actionable suggestions.
- 🗺️ **Domain Roadmaps**: Curated preparation tracks for Software Development, Data Analytics, AI/ML, and Cybersecurity.
- 💻 **Code Studio**: Interactive problem-solving space with algorithmic challenges, hints, and language templates.
- 🌓 **Dark & Light Mode**: Seamless theme switching with persistent local storage.

## 🚀 Getting Started

No build step or dependencies required! SkillTrack runs natively in any modern web browser.

### Option 1: Live GitHub Pages
Visit the live site directly:
👉 [https://pauljebakumar.github.io/SkillTrack/](https://pauljebakumar.github.io/SkillTrack/)

### Option 2: Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/pauljebakumar/SkillTrack.git
   cd SkillTrack
   ```
2. Open `index.html` in your web browser:
   - On Windows: double-click `index.html` or run `start index.html`
   - Using VS Code: Right-click `index.html` and choose "Open with Live Server"
   - Or start a local server:
     ```bash
     npx serve .
     ```
